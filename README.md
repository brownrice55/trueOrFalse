# TrueOrFalse

> まるばつクイズ（選択問題も入れることにしたので、後で名前を変更予定）

<p>難しいことを覚えるのが難しいので、まるばつクイズや選択問題にして覚えてみることにした。</p>

## 基本機能

<ul>
<li>問題と答え、解説を登録できる</li>
<li>一覧から詳細を表示できる</li>
<li>詳細から編集と削除ができる</li>
<li>クイズを表示できる</li>
<li>クイズに答えて正誤を確認できる</li>
</ul>

### グローバルメニュー

<ul>
<li>クイズスタート</li>
<li>クイズ一覧</li>
<li>新規登録</li>
<li>カテゴリー設定</li>
</ul>
