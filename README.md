# TrueOrFalse

> まるばつクイズ

<p>難しいことを覚えるのが難しいので、まるばつクイズにして覚えてみることにした。</p>

## 基本機能

<ul>
<li>問題と答え、解説を登録できる</li>
<li>一覧から詳細を表示できる</li>
<li>詳細から編集と削除ができる</li>
<li>クイズを表示できる</li>
<li>クイズに答えて正誤を確認できる</li>
</ul>

### グローバルメニュー

<ul>
<li>クイズ</li>
<li>クイズ一覧</li>
<li>新規登録</li>
</ul>
