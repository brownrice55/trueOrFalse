# TrueOrFalse

> まるばつクイズ（選択問題も入れることにしたので、後で名前を変更予定）

<p>難しいことを覚えるのが難しいので、まるばつクイズや選択問題にして覚えてみることにした。</p>

## 基本機能

<ul>
<li>問題と答え、解説を登録できる</li>
<li>一覧から詳細を表示できる</li>
<li>詳細から編集と削除ができる</li>
<li>クイズを表示できる</li>
<li>クイズに答えて正誤を確認できる</li>
</ul>

### グローバルメニュー

<ul>
<li>クイズスタート</li>
<li>クイズ一覧</li>
<li>新規登録</li>
<li>カテゴリー設定</li>
</ul>

#### クイズ詳細・新規登録の「カテゴリー追加」から遷移してカテゴリー設定で保存した後に、次に何をするか確認

<p>関数名：displayModalToSelectWhetherToGoBackQuizDetailAfterSavingData</p>

<ul>
<li>カテゴリー設定で保存した際に、クイズスタート・クイズ一覧・新規登録でカテゴリー名を更新する。</li>
<li>クイズ一覧・新規登録から「カテゴリー追加」でカテゴリー設定に飛んでカテゴリー名を変更・保存した後に来たページに戻る場合は、入力していた状態に戻るように、カテゴリー設定に飛ぶ前に入力していた値を保持して、各ページのカテゴリー名を更新後に再表示する必要がある。</li>
</ul>
